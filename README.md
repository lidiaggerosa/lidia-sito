# lidia-sito

Sorgenti del sito lidiatech.ai: tema WordPress `lidia`, pagine in blocchi, contenuti e strumenti di rilascio.

- Istruzioni di lavoro: `CLAUDE.md`
- Stato del sito: `STATO.md`
- Rilasci: `REGISTRO.md` · differenze staging/produzione: `DISALLINEAMENTI.md`

Pubblicare: `.\strumenti\pubblica.ps1 <slug>` (staging) · `... -Produzione`.
Salvare su GitHub: `.\strumenti\salva.ps1 "cosa"`.
